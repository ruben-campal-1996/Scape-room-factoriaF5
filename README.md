🧠 Enfoque de Análisis Técnico

El análisis técnico del proyecto se basa principalmente en su organización interna (carpetado). La estructura de directorios no es casual: está diseñada para separar responsabilidades, mejorar la mantenibilidad y permitir una navegación intuitiva.

A continuación se describe la arquitectura general del proyecto:

TEMPLATES🗂️ / RETO.HTML📝 RESULTADO.HTML
.GITIGNORE📝

Cada carpeta y archivo tiene un propósito específico dentro del sistema, contribuyendo a una arquitectura limpia y coherente.
